# Harborline Auto Care — Website Demo

Harborline Auto Care is a fictional auto-repair website concept created by **Glanzberg Web** to demonstrate how a modern local-service website can present services clearly, build trust quickly, and convert visitors into calls and appointment requests.

## Demo highlights

- Responsive desktop and mobile layout
- Click-to-call contact actions
- Service and trust sections
- Customer-review presentation
- Appointment-request form demonstration
- Static architecture suitable for GitHub Pages

## Important

Harborline Auto Care is not a real business. Names, reviews, ratings, hours, warranties, phone numbers, and service details on this site are sample content used solely for demonstration.

The service-request form is intentionally configured as a demo and does not send information to a real repair shop.
